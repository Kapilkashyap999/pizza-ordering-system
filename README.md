# Pizza Ordering System

This is a simple Python-based console application that allows users to place a pizza order. The program collects user details, validates inputs, and provides an order summary with the selected pizza, size, toppings, and drink.

## Features

- **User Details Input**: Collects the user's name, location, and phone number.
- **Pizza Selection**: Offers a menu of pizzas to choose from.
- **Size Selection**: Allows users to select the size of the pizza (Small, Medium, Large).
- **Toppings Selection**: Provides a list of available toppings for customization.
- **Drink Selection**: Includes popular drink options like Coke, Pepsi, and Sprite.
- **Order Summary**: Displays a detailed summary of the order, confirming all selections.
